Features
--------

- Added a "Cyberspace" theme to the book list: a home page from the first years of the web, in green on black over a wireframe floor, with each book on a bevelled panel and the text in VT323, a terminal font that is bundled with the theme (a 6 KB subset, under the SIL Open Font License) and only downloaded when the theme is chosen. Like the other built-in themes, it uses no images or JavaScript.
