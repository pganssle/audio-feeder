Features
--------

- Themes with a light and a dark version (Classic, Shelf and Plain) can now be set to always be light or always be dark, rather than following the system's setting, with the new "Light / Dark / System" choice in the menu. The choice is remembered by the browser, like the theme. Custom themes offer this choice if they set ``color-scheme: light dark``; see the documentation on themes for how to write the dark version.

- The theme is now chosen at the top of the menu, rather than in a collapsed "Appearance" section at the bottom, and the folders, filters and tags are grouped under "Browse" below it, with the key to the include and exclude buttons.
